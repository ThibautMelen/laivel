# laivel · hackathon project

72h hackathon build for LAIVEL UP (AI-Driven Dev). Optimize for the demo, not for maintenance.

## Operating mode

- Ship > polish. A command that runs beats a dashboard that doesn't.
- The demo script (see README) is the spec. Build backward from it.
- Cut features when behind, never the demo path.
- Keep secrets in `.env` (gitignored). Never hardcode keys.
